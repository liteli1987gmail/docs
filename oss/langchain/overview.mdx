LangChain is an open source framework with a prebuilt agent architecture and integrations for any model or tool. You can build a fully functional AI agent in under 10 lines of code, then swap providers, add tools, or customize behavior without rewriting your application logic.

<Tip>
**LangChain vs. LangGraph vs. Deep Agents**

Start with [Deep Agents](/oss/deepagents/overview/) for a "batteries-included" agent with features like automatic context compression, a virtual filesystem, and subagent spawning.

Use LangChain agents when you want fine-grained control over tools, prompts, and models. Use [LangGraph](/oss/langgraph/overview) when you need low-level orchestration with explicit state and graph structure.
</Tip>

## Create an agent

The example below creates a weather agent with a single tool. Swap the model string to use a different provider—no other changes needed.

<Tabs>
  <Tab title="Python">
    ```python
    # pip install -qU langchain "langchain[openai]"
    from langchain.agents import create_agent

    def get_weather(city: str) -> str:
        """Get weather for a given city."""
        return f"It's always sunny in {city}!"

    agent = create_agent(
        model="openai:gpt-5.4",
        tools=[get_weather],
        system_prompt="You are a helpful assistant",
    )

    result = agent.invoke(
        {"messages": [{"role": "user", "content": "What's the weather in San Francisco?"}]}
    )
    print(result["messages"][-1].content_blocks)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```ts
    // npm install langchain zod @langchain/openai
    import { createAgent, tool } from "langchain";
    import * as z from "zod";

    const getWeather = tool(
      (input) => `It's always sunny in ${input.city}!`,
      {
        name: "get_weather",
        description: "Get the weather for a given city",
        schema: z.object({
          city: z.string().describe("The city to get the weather for"),
        }),
      }
    );

    const agent = createAgent({
      model: "gpt-5.4",
      tools: [getWeather],
    });

    console.log(
      await agent.invoke({
        messages: [{ role: "user", content: "What's the weather in San Francisco?" }],
      })
    );
    ```
  </Tab>
</Tabs>

See the [Quickstart](/oss/langchain-quickstart) to run this in minutes.

## Core benefits

<CardGroup cols={2}>
  <Card title="Standard model interface" icon="refresh" href="/oss/langchain/models">
    Different providers have unique APIs and response formats. LangChain standardizes how you interact with models so you can swap providers without rewriting your application.
  </Card>

  <Card title="Easy to use, highly flexible agent" icon="wand" href="/oss/langchain/agents">
    Build a simple agent in under 10 lines of code. Add tools, custom prompts, streaming, and structured output as your needs grow.
  </Card>

  <Card title="Built on LangGraph" icon="chart-dots" href="/oss/langgraph/overview">
    LangChain agents are built on top of LangGraph, giving you durable execution, human-in-the-loop support, and persistence without extra configuration.
  </Card>

  <Card title="Debug with LangSmith" icon="eye" href="/langsmith/tracing">
