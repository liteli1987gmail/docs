LangChain offers an extensive ecosystem with over 1,000 integrations across chat models, embedding models, tools, vector stores, document loaders, and more. Every integration implements a standard LangChain interface, so you can swap providers without rewriting your application code.

A **provider** is a company or platform that hosts AI models and exposes them via an API (for example, OpenAI, Anthropic, or Google). Many providers have a dedicated `langchain-<provider>` package that implements one or more of LangChain's standard interfaces. Install the package, pick a model name, and switch providers by changing a single string.

## How provider packages work

Most providers ship a package named `langchain-<provider>` that you install alongside `langchain-core`. The package exposes one or more classes that implement LangChain's standard interfaces:

```python
# Each provider follows the same pattern:
# pip install langchain-<provider>
from langchain_openai import ChatOpenAI
from langchain_anthropic import ChatAnthropic
from langchain_google_genai import ChatGoogleGenerativeAI

# Swap providers by changing the class—your chain stays the same
model = ChatOpenAI(model="gpt-5.4-mini")
model = ChatAnthropic(model="claude-sonnet-4-6")
model = ChatGoogleGenerativeAI(model="gemini-3.1-pro-preview")
```

You can also use `init_chat_model` to load any provider from a single function call using the `provider:model` string format:

```python
from langchain.chat_models import init_chat_model

model = init_chat_model("openai:gpt-5.4-mini")
model = init_chat_model("anthropic:claude-sonnet-4-6")
model = init_chat_model("google_genai:gemini-3.1-pro-preview")
```

## Community integrations

Integrations that do not have a dedicated first-party package are available in `langchain-community`. This includes hundreds of vector stores, document loaders, and tool integrations maintained by the LangChain community.

```bash
pip install langchain-community
```
