Fleet templates are pre-configured agents built for common use cases. Each template includes a system prompt, a curated set of tools, and optionally pre-configured channels. You clone a template to create your own independent copy that you can customize without affecting the original.

<Tip>
If you're new to Fleet, follow the [quickstart](/fleet/quickstart) to build your first agent using the Email Assistant template.
</Tip>

## What's included in a template

Each template bundles:

- **Instructions** — A system prompt defining the agent's behavior and capabilities. You can edit this to match your specific needs.
- **Tools** — Pre-selected integrations the agent needs to do its job (for example, Gmail and Google Calendar for an email assistant).
- **Channels** (optional) — Some templates include a trigger channel so the agent activates automatically on new events.

## Use a template

<Steps>
  <Step title="Open Fleet">
    In the LangSmith UI, click **Switch to Fleet** in the left navigation.
  </Step>
  <Step title="Browse templates">
    Select **Templates** in the left navigation to see all available templates.
  </Step>
  <Step title="Clone the template">
    Select a template and click **Use this template**. You'll be prompted to connect any required accounts.
  </Step>
  <Step title="Customize and save">
    Review and edit the instructions, add or remove tools, and adjust channels. Click **Save changes** when done.
  </Step>
</Steps>
