Tools give your Fleet agent the ability to take real-world actions — reading emails, searching the web, creating issues, sending Slack messages, and more. You can add tools to a specific agent or make them available to all agents in your workspace.

## Add a tool

<Tabs>
  <Tab title="To a specific agent">
    1. In [Fleet](https://smith.langchain.com/agents), open the agent you want to update.
    2. Click the **Edit Agent** icon next to the agent name.
    3. In the graph view, navigate to the **Toolbox** section and click **+ Add**.
    4. Select the tool and follow the authentication prompts.
    5. Click **Save Changes**.
  </Tab>
  <Tab title="To all agents (workspace)">
    1. Navigate to the [Fleet > Integrations tab](https://smith.langchain.com/agents/tools).
    2. Find the tool you want to add and click **Connect**.
    3. Follow the prompts to authenticate and connect.
  </Tab>
</Tabs>

## Remove a tool

<Steps>
  <Step title="Open the agent editor">
    In [Fleet](https://smith.langchain.com/agents), select your agent and click the **Edit Agent** icon.
  </Step>
  <Step title="Remove the tool">
    In the **Toolbox** section, find the tool and click the trash icon next to it.
  </Step>
  <Step title="Save">
    Click **Save Changes**.
  </Step>
</Steps>
