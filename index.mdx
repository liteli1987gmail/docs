## Choose your path

<Steps>
  <Step title="Sign up for LangSmith">
    Create a free account at [smith.langchain.com](https://smith.langchain.com). No credit card required.
  </Step>
  <Step title="Install an SDK">
    Install the LangSmith SDK for Python or JavaScript and set your API key to start tracing.
  </Step>
  <Step title="Build an agent">
    Use LangChain, LangGraph, or Deep Agents to build your agent logic. LangSmith traces everything automatically.
  </Step>
  <Step title="Evaluate and deploy">
    Run evaluations against datasets, iterate on prompts, and deploy your agent via the Agent Server.
  </Step>
</Steps>
